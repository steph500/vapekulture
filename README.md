# Vapekulture

Single-page premium vape brand website built with React, Vite, TypeScript, and Tailwind CSS.

## Scripts

- `npm install`: install dependencies
- `npm run dev`: start the local development server
- `npm run build`: create a production build
- `npm run preview`: preview the production build locally

## Structure

- `src/App.tsx`: main single-page site layout and content
- `src/components/`: reusable UI components
- `src/data.ts`: product, flavour, and navigation content
- `src/index.css`: Tailwind layers and custom neon glass styling
